Before or during current web research, attempt to fetch the shared context file from:

- Repository: `andrasmining/tradebrain`
- Branch: `main`
- Path: `data/finviz/latest.json`

Treat this file only as deterministic supplementary evidence. It is not a provider, does not own a signal, and never replaces current web research, authoritative sources, or fresh NQ price-path evidence.

Validate that the payload is structurally usable, that `source` is `finviz`, and that `generatedAt` is a valid UTC timestamp. Context no more than 90 minutes old is reasonably fresh for supporting use. Treat older context as stale. Respect the file's `collectionStatus`, section-level availability and completeness metadata (including `coverageStatus` and `missingSymbols` where present), warnings, and delayed-data labels.

If the file is missing, stale, malformed, unavailable, or partial, continue the full independent research and assessment. Never fail or delay publication solely because Finviz context is unhealthy.

## Evidence-use rules

1. Use fresh available breadth, megacap, and semiconductor sections only as confirmation or conflict evidence.
2. `generatedAt` is the collection time, not a market observation timestamp. Breadth, megacap, and semiconductor daily changes are labeled latest-session, non-real-time context with source as-of not provided; never treat them as evidence of live current NQ structure.
3. Conflicting breadth normally reduces directional conviction or increases uncertainty; it does not mechanically increase Tail.
4. Strong aligned breadth may amplify Tail only when fresh independent evidence also shows persistent directional NQ structure, shallow or failed retracements, repeated extension, or similar mean-reversion failure.
5. Use the economic calendar as a supplementary structured feed. Verify material U.S. release timing, actuals, and event details with authoritative current sources before relying on them.
6. Use Finviz headlines for discovery only. Verify every material story with reputable or primary current sources before using it materially in Tail, Stress, or Confidence reasoning.
7. Treat Finviz futures as delayed/contextual cross-asset evidence, never as live NQ price-path evidence. Do not use it as the primary source for immediate post-event continuation, shallow pullbacks, failed retracements, session-extreme holding, one-way structure, or current Tail action.
8. Use the bounded earnings section only for supplementary catalyst discovery. Verify any material earnings date and session timing elsewhere before relying on it, and never invent an exact release time when the source does not provide one.
9. Event importance or `actual != expected` primarily informs Stress and Confidence until observed price-path evidence establishes persistent Tail behavior.
10. Do not automatically raise Tail because an event exists, a release differs from expectations, or Finviz reports a large daily futures move.
11. Finviz context never supersedes fresher contradictory evidence.
12. Do not persist the complete Finviz payload into a provider snapshot. Public output may reference only conclusions and evidence actually used, subject to all existing public-safety and source rules.
